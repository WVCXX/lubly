# Электронная валентинка

Одностраничное приложение-путешествие на React, Vite, Tailwind CSS и Framer Motion.

После ответа «Да» и открытия конверта можно возвращаться к предыдущим этапам жестом вверх или вправо; на компьютере — прокруткой колеса вверх.

## Персонализация

Перед публикацией откройте `src/data.js` и замените имя, подписи, благодарность и варианты ответа на свои. Положите изображения в `public/photos/` с именами `1.jpg`, `2.jpg`, `3.jpg` и `4.jpg`. Чтобы использовать другие пути, измените `src` у фотографий в `src/data.js`.

## Установка и запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Для production-сборки и локального просмотра:

```bash
npm run build
npm run preview
```

## Деплой на Vercel

1. Загрузите проект в GitHub, GitLab или Bitbucket.
2. Импортируйте репозиторий в Vercel.
3. Оставьте preset `Vite`, команду сборки `npm run build` и папку вывода `dist`.
4. Нажмите **Deploy**. Правило в `vercel.json` поддерживает переходы внутри одностраничного приложения.

Также можно установить Vercel CLI и выполнить `vercel` из папки проекта.
