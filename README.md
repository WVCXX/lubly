# Электронная валентинка

Одностраничное приложение-путешествие на React, Vite, Tailwind CSS и Framer Motion.

После ответа «Да» и открытия конверта можно возвращаться к предыдущим этапам жестом вверх или вправо; на компьютере — прокруткой колеса вверх.

## Персонализация

Перед публикацией откройте `src/data.js` и замените имя, подписи, благодарность и варианты ответа на свои. Положите изображения в `public/photos/` с именами `1.jpg`, `2.jpg`, `3.jpg` и `4.jpg`. Чтобы использовать другие пути, измените `src` у фотографий в `src/data.js`.

## Установка и запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Для production-сборки и локального просмотра:

```bash
npm run build
npm run preview
```

## Деплой на Vercel

1. Загрузите проект в GitHub, GitLab или Bitbucket.
2. Импортируйте репозиторий в Vercel.
3. Оставьте preset `Vite`, команду сборки `npm run build` и папку вывода `dist`.
4. Нажмите **Deploy**. Правило в `vercel.json` поддерживает переходы внутри одностраничного приложения.

Также можно установить Vercel CLI и выполнить `vercel` из папки проекта.

## Публикация на GitHub Pages

В репозитории уже настроена автоматическая публикация через GitHub Actions. После каждого push в ветку `main` сайт собирается и обновляется автоматически.

1. Создайте пустой репозиторий на GitHub.
2. В корне проекта выполните команды, заменив `ВАШ_АККАУНТ` и `ИМЯ_РЕПОЗИТОРИЯ` на свои:

   ```bash
   git init
   git add .
   git commit -m "Initial valentine site"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/ИМЯ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```

3. В настройках репозитория откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Source: GitHub Actions** (не **Deploy from a branch**) и сохраните настройку. Публикация из ветки отдаёт исходный `index.html`, который не запускается без сборки.
4. Откройте вкладку **Actions**, выберите workflow `Deploy to GitHub Pages` и запустите **Run workflow** для ветки `main` (или отправьте новый commit в `main`). Дождитесь зелёного статуса для build и deploy.
5. Ссылка появится в **Settings → Pages**. Для обычного репозитория она имеет вид `https://ВАШ_АККАУНТ.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

Если Git не настроен, установите его и выполните вход в GitHub. Не добавляйте `node_modules` или секреты в репозиторий; `node_modules` уже указан в `.gitignore`.
